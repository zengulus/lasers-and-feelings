HOW THIS STAYS SHARED

Pass the briefing, not the burden.

This site is made for GitHub Pages, so it does not run a server or track anyone. The DM’s Copy player snapshot button puts the current phase, scene, directive, risk, and clock into a link.

Drop that link in your group chat. Anyone who opens it gets the same player-facing mission brief. It is a point-in-time snapshot, so send a fresh link after each update. Characters and notes stay on each player’s own device.

DM notes are excluded from these links, but this is not a security boundary. Keep the DM console on a device players cannot browse.
